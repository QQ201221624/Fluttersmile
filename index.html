内核报错 (手机自动重启)
kernel abnormal reboot records : AP_WDT timeout , Power_keys_long_press
📌 问题摘要 内核因应用看门狗(AP_WDT)超时主动关机并重启
🎯 原因定位 系统关键进程未及时喂狗，触发硬件超时复位(高负载/死锁)
🛠️ 解决方案 抓取调用栈 → 排查可疑应用 → 恢复出厂/检测主板
MySQL连接拒绝
ERROR 2003 (HY000): Can't connect to MySQL server on 'localhost' (10061)
📌 问题摘要 本地MySQL连接被拒绝，网络层连接错误
🎯 原因定位 MySQL服务未启动 或 3306端口拦截
🛠️ 解决方案 systemctl start mysql & ufw allow 3306
sudo systemctl status mysql → sudo systemctl start mysql → sudo ufw allow 3306
